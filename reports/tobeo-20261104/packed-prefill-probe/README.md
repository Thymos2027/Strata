## 已核对的接口

当前源码include/strata/prefill/prefill.hpp的init接收一个SessionState，run接收一条tokens序列、长度和起始位置。prefill.cpp对该会话的GDN递归、QSA状态和PLE历史进行更新。多客户端HTTP请求仍串行进入输入读取控制路径。拼接提示词会改变注意力和递归语义，不能作独立请求packed prefill的正确性对照。以上为静态审查，不是完整兼容性证明。

## 本轮算子协议

- 取现有IQ3_S GGUF第0层真实attn_qkv(Q6_K)、attn_gate(Q4_K)、路由专家0的gate(IQ3_XXS)和down(IQ4_NL)矩阵；保留原始量化字节和SHA。模型标签IQ3_S不代表每个张量都是该格式。
- 使用本机已有870aedd9/0.1.54静态库中的Strata Gemm::native，独立编译CUDA/sm120探针。记录库、头文件和探针哈希。日常服务此前为0.1.52，本实验不是其完整prefill实现或跨版本性能对比。
- 激活为固定seed的合成FP16行；每请求64/256/1024行，2/4请求。A对相同行分段执行B次小GEMM，B按原行顺序执行一次大GEMM。每矩阵6种布局，共24个正确性门槛、48个计时工况。
- 每工况比较权重已驻留GPU、每请求从pinned主存搬入权重两模式。流式B只搬一次同一权重；这是多个请求路由到同一专家且可以合并时的条件性收益，不代表真实路由分布。resident不计初始上传；native调用包括原路径的反量化等内部成本。
- A/B输出全量比较：必须全部有限，NRMSE<=0.002且max_abs_error<=0.01+0.002*max_abs_reference；这是算子数值门槛，不是全模型质量或输出身份验收。失败即停，不继续计算该工况性能。
- 预热后五组交替顺序配对，每臂10次，CUDA事件计时。记录原始毫秒、配对比、中位数和范围。计时不含输入打包、attention/GDN/PLE、完整MoE路由、状态保存恢复、排队或decode；不能把A/B比直接称为模型加速比。

## 后台执行和停止

先构建并校验权重抽取，再检查GPU环境。有可识别且空闲的8080日常服务时暂时停止并在finally恢复；服务原本不存在时保持不存在，不擅自启动。GPU可用显存不足2GiB或利用率大于10%时停止GPU实验。每个原生探针最长180秒，构建最长20分钟；内存guard连续三次5秒采样低于3GiB物理余量或2GiB提交余量则终止当前探针。各步骤失败即停，保留日志。
